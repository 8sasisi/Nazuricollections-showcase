# Grant Fashions Showcase

A premium-fashion static frontend for Grant Fashions, built to reflect the brand’s elegant, contemporary modest fashion identity.

## Features
- Premium editorial homepage with luxury boutique styling
- Dedicated Abayas collection page
- Dedicated Magauni / Gowns collection page
- About and Contact pages
- Responsive Bootstrap-powered layout
- WhatsApp and social placeholders configured for brand contact links

## Local preview
From the project root, run:

```bash
py -m http.server 8000
```

Then open:

- http://localhost:8000/index.html

## Notes
- The site uses Bootstrap 5, Bootstrap Icons, and vanilla JavaScript.
- Placeholder WhatsApp/social links remain in place until official business details are provided.
- The implementation follows the documented brand requirements in the Documents folder.
